# Aurum & Co. Jewellery Storefront

A polished responsive e-commerce demo for a jewellery shopping website.

## Included
- Login + create-account UI
- 24 products split between men's and women's jewellery
- Product search, category filters, wishlist buttons and ratings
- Add-to-bag, quantity controls and localStorage persistence
- Coupon `WELCOME10` for 10% off
- Checkout flow: delivery → UPI/card/COD → review → demo order confirmation
- Demo order tracking timeline
- Style quiz with personalised collection suggestion
- Customer-support chatbot
- Responsive mobile navigation
- Offers, reviews, trust badges and gift messaging

## Run
Open `index.html` in a browser. No build step or server is required.

## Images
The storefront uses jewellery photography loaded from public image hosts, including Unsplash and several jewellery product pages, to give the demo realistic product visuals. For a commercial deployment, replace third-party image URLs with images you have the right to use. Unsplash states that its free images can generally be used for commercial projects, subject to its license and additional rights such as trademarks or recognizable people.

## Important
This is a front-end demo. Login, payment, order placement and tracking are simulated in the browser. For a production store, connect a real backend, authentication system, inventory database, shipping provider and payment gateway (e.g. Razorpay/Stripe) before accepting real orders.
